# Manual Checks — Сборный заход: количество в корзине и значок корзины

[COVERS] = 4f2a9c1

[STYLE] = brief

[PASS] = 01, 02

## Scope

Один заход по кейсам двух шагов: 01, степпер количества в корзине, и 02, значок на иконке корзины. Язык интерфейса — русский. Пять кейсов в двух сеансах, около пятнадцати минут.
Остальные кейсы обоих шагов агент прошёл на симуляторе; 01/MC-1 вернулся от него, потому что драйвер не смог войти в учётную запись.
Шаги собирали сцены по-разному. Шаг 01 входил под cart.tester.1, шаг 02 — под cart.tester.2; заход берёт cart.tester.1 для обоих. Шаг 01 начинал с открытой корзины, шаг 02 — с главного экрана; заход начинает с открытой корзины. Сцены обоих шагов описывали одно состояние, поэтому слиты в одну.

## Preparation

### S1. Корзина с зелёным чаем

Войти тестовой учётной записью cart.tester.1; её пароль — на командной странице тестовых учётных записей.
Положить в корзину «Зелёный чай» в количестве, которое называет Start кейса, и открыть корзину.

## Cases

### Session 1. Любое устройство, около десяти минут

#### 01/MC-1. Плюс увеличивает количество и итог

**What it checks:** одно нажатие на плюс добавляет одну штуку, и итог растёт на её цену.

**Runner:** agent

**Order:** first — корзина должна быть нетронутой с момента входа

**Start:** S1 с одним зелёным чаем.

1. Нажать плюс в строке «Зелёный чай»
   → Количество 2, итог «Итого 9,00»

**Failure looks like:** количество 2, а итог по-прежнему 4,50.

#### 02/MC-1. Значок считает штуки, а не строки

**What it checks:** значок на иконке корзины показывает число штук.

**Start:** S1 с двумя зелёными чаями.

1. Посмотреть на значок на иконке корзины
   → На значке 2
2. Нажать иконку корзины справа вверху
   → В корзине одна строка «Зелёный чай», количество 2

**Failure looks like:** на значке 1.

#### 02/MC-2. Значок исчезает вместе с последним товаром

**What it checks:** значок пропадает, когда корзина пустеет.

**Start:** S1 с одним зелёным чаем.

1. Нажать минус в строке «Зелёный чай»
   → Строка исчезает, посередине экрана надпись «Корзина пуста»
2. Посмотреть на иконку корзины справа вверху
   → У иконки корзины нет значка

**Failure looks like:** над пустой корзиной на значке всё ещё 1.

#### 02/MC-3. Значок переживает выход и повторный вход

**What it checks:** после повторного входа значок показывает сохранённую корзину.

**Order:** last — он выводит тестовую учётную запись из системы

**Start:** S1 с одним зелёным чаем.

1. Выйти на экране профиля и снова войти той же учётной записью
   → Открывается главный экран
2. Посмотреть на иконку корзины справа вверху
   → На значке 1

**Failure looks like:** после входа значка нет.

### Session 2. Настоящее устройство, около пяти минут

#### 01/MC-2. Протягивание корзины вниз обновляет её со скоростью пальца

**What it checks:** быстрое протягивание списка корзины вниз обновляет его один раз, и индикатор пропадает.

**Device:** real

**Start:** S1 с одним зелёным чаем.

1. Быстро протянуть список корзины вниз и отпустить
   → Индикатор появляется один раз и пропадает, строка остаётся

**Failure looks like:** индикатор остаётся на экране или строка пропадает.
