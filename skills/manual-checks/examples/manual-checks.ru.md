## Scope

Теперь покупатель меняет количество товара прямо в корзине, не уходя с неё.
Итог и число на значке корзины меняются сразу, а пустая корзина говорит, что она пуста.
Автотесты проверили расчёт итога и предел в 10 штук одного товара.
Здесь проверяется то, что видит человек: три кейса, около пятнадцати минут.

## Preparation

### Карта экрана

```
Страница товара                 Корзина
+--------------------------+    +------------------------------+
| < Назад      [корзина] 2 |    | < Назад  Корзина [корзина] 2 |
| Зелёный чай              |    |------------------------------|
| 4,50                     |    | Зелёный чай [-] 2 [+]   9,00 |
| Количество [ 1 v ]       |    | Не больше 10 штук            |
| [ В корзину ]            |    |------------------------------|
+--------------------------+    | Итого 9,00     [ Оформить ]  |
                                +------------------------------+
```

| Слово в кейсах | Что это на экране |
|---|---|
| иконка корзины | тележка справа вверху на любом экране; нажатие открывает корзину |
| значок | красный кружок с числом на иконке корзины; число — сколько штук в корзине, а не сколько строк |
| строка | один товар в корзине: название, кнопки количества и цена |
| кнопки количества | минус, число и плюс в строке товара |
| итог | строка «Итого» над кнопкой «Оформить» |
| надпись о пределе | серая строка «Не больше 10 штук» под строкой товара, когда количество дошло до 10 |

### П0. Сборка

**dev-only:** разработчик ставит на тестовое устройство сборку из Run record и выходит из учётной записи, если в приложении она осталась. Тестировщик начинает после этого.

### П1. Устройство

- Язык интерфейса — русский: все подписи в кейсах взяты из русской версии приложения.
- Тестовая учётная запись указана в Test data каждого кейса; её пароль — на командной странице тестовых учётных записей.

### П2. Корзина с одним зелёным чаем

| # | Action | Expected |
|---|---|---|
| 1 | Открыть приложение | Экран входа |
| 2 | Войти учётной записью из Test data кейса | Главный экран; на иконке корзины нет значка |
| 3 | Ввести «Зелёный чай» в поле поиска вверху | Один результат: «Зелёный чай», 4,50 |
| 4 | Нажать на результат «Зелёный чай» | Страница товара «Зелёный чай», количество 1 |
| 5 | Нажать «В корзину» | На значке корзины 1 |

Если до шага 5 на значке уже есть число, корзина учётной записи не пуста: отметить кейс как BLOCKED и записать это число.

## Cases

### MC-1. Плюс увеличивает количество, итог и число на значке

**Priority:** P1 — главный сценарий

**Traces to:** Plan.md, Manual acceptance, п. 1

**What it checks:** одно нажатие на плюс добавляет одну штуку, итог растёт на её цену, а значок считает штуки.

**Preconditions:**

- Корзина с одним зелёным чаем (Preparation, П2).

**Test data:** учётная запись cart.tester.1; «Зелёный чай» за 4,50.

**Steps:**

| # | Action | Data | Expected | Actual |
|---|---|---|---|---|
| 1 | Нажать иконку корзины справа вверху | — | В корзине одна строка: «Зелёный чай», количество 1, итог 4,50 | |
| 2 | Нажать плюс в строке «Зелёный чай» | — | Количество 2, цена в строке 9,00 | |
| 3 | Посмотреть на итог над кнопкой «Оформить» | — | «Итого 9,00» | |
| 4 | Посмотреть на значок на иконке корзины | — | На значке 2 | |

**Expected result:** в корзине два «Зелёный чай», итог 9,00, на значке 2.

**By instrument:** корзина на сервере совпадает с экраном. Разработчик выполняет `curl -s -H "Authorization: Bearer <token>" https://shop.example.com/api/cart` с токеном тестовой учётной записи и читает поле `item_count`: оно должно быть 2.

**Failure looks like:** количество 2, а итог по-прежнему 4,50, или на значке всё ещё 1.

**Cleanup:** нажимать минус в строке «Зелёный чай», пока строка не исчезнет.

## Not covered

- Оплата заказа: экран оформления в этой задаче не менялся.
- Корзина на двух устройствах сразу: синхронизация между устройствами — следующий шаг эпика.

## Troubleshooting

| Symptom | Cause | What to do |
|---|---|---|
| На значке есть число ещё до П2 | В тестовой учётной записи осталась корзина от прошлого прогона | Опустошить корзину минусами и начать П2 заново |
| В поиске нет «Зелёный чай» | Устройство без сети, или каталог ещё загружается | Проверить сеть, подождать десять секунд и повторить поиск |
